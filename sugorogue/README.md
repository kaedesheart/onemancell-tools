# スゴローグ — 試遊版

移動ダイスと手札3枚を全部振り、ボードに表示された着地点を選ぶ、すごろく×ローグライト。

## 遊べる内容

- D20 → D200 → D2000 → D20000の4章。出口は通過でクリア。
- 符号・倍率・微調整・防御の組み合わせを自動計算。同じ位置なら被害の少ない組み合わせを採用する。
- 宝箱、金鉱、ショップ、焚き火、無料削除の祭壇。報酬は同じ場所で1回だけ。
- 後半は強制的な負の出目を持つ呪いが加わる。浄化を一緒に振ると呪い1枚を無効化してデッキから除去できる。
- 山札と捨て札、購入・強化・削除、HP、クリア・敗北・再挑戦。
- 端末内の途中保存。出目と報酬候補も保存し、再読み込みで再抽選しない。

## 実行

必要なのはNode.js 22以降。外部パッケージのインストールは不要。

```sh
cd sugorogue
npm run dev
# http://127.0.0.1:4173/
npm test
npm run build
node scripts/simulate.mjs
```

既存のGitHub Pagesと同じく、HTML・CSS・ES Modulesのみで動作する。リポジトリの `/sugorogue/` で配信可能。ビルドは試遊版をリポジトリ直下の `dist/` にコピーする。開発サーバーにHMRはないため、編集後はページを再読み込みする。

## 設計・実装

- `src/state.js`：乱数、状態遷移、着地候補、経済、保存検証。DOMに依存しない。
- `src/dice.js`：ダイス定義と選択可能な効果。
- `src/board.js`：章・盤面生成・報酬範囲・着地被害。
- `src/render.js`：一本道と、座標に結び付いた着地ボタン。
- `src/ui.js`：手札、結果、ショップ等の表示。
- `src/main.js`：UIイベント、端末保存、画面遷移。

## 初期企画からの更新

ユーザーの操作提案に合わせ、手札の選択と符号の個別操作を廃止。毎回手札3枚を全部振り、着地点を直接選ぶ。所持デッキ全体を同時に振る仕様ではない。

後半に報酬への着地が極端に難しくなる問題を避けるため、効果マスに章スケールの半分の半径を持たせた。第1章は整数1点、第2章は中心±5、第3章は±50、第4章は±500。範囲外の近接領域は4ダメージ、それ以外は章ごとに12/14/16/18ダメージ。範囲と予測被害は画面に表示する。

章移行でランダム±ダイスと呪いの桁を引き上げ、HP30回復・次章通貨20単位分・ダイス報酬を提供する。同時に呪い1枚が加わるが、章報酬には浄化を必ず含める。固定補正は小さいまま残す。

呪いによって前進量が0以下になった場合は、後ろへ移動せず、その場で基礎8ダメージを受けて次の手札へ進む。浄化による除去は移動確定時に行い、プレビューにも表示する。デッキは3枚を下限とする。

「振るだけでHPを失うダイス」、倍率の重ねがけ、遺物、恒久解放、エンドレスは未実装。崩壊度も未導入。数値は試遊用で、最終的な難易度ではない。

## 検証

`npm test` は、候補と確定結果の一致、全手札ロール、重複報酬防止、負の補正・足止め・浄化、章移行、購入・強化・削除、再シャッフル、保存再開・破損データ拒否を検証する。

`simulate.mjs` は200個の固定seedを単純な自動方策で進める。実際の人のクリア率・楽しさ・所要時間を測定するものではない。加えて開発時にJSDOMで、開始からボード選択・移動・報酬・保存再開・結果・再挑戦までのUIイベントを検証した。実機ブラウザの見た目・タッチ操作のQAは未実施。
