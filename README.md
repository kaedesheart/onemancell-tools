## アクセス計測（Google アナリティクス 4）

測定IDは `analytics.js` の `MEASUREMENT_ID` だけに書く。現在の値は `G-TZ9JMLVKTL`。空、または `G-XXXX` のようなプレースホルダーに戻すと、タグを読み込まず何も送信しない。

全HTMLページがこのファイルを読み、ページを開いたときの閲覧（`page_view`。GA4 の自動送信）を測る。スイングバイだけ、次のカスタムイベントを追加で送る。観るだけモードでは送らない。氏名などの個人情報は送らない。

| イベント名 | タイミング | パラメータ |
| --- | --- | --- |
| `page_view` | 各ページを開いたとき | なし（ページの URL は GA4 が付ける） |
| `game_start` | スタート、またはクリア後の「もう一度」でプレイを開始したとき | `stage`（開始ステージ。通常は 1） |
| `level_complete` | ステージをクリアしたとき（最終ステージを含む） | `stage`（クリアしたステージ番号）、`shots`（そのステージの発射数）、`all_clear`（最終ステージなら 1、それ以外は 0） |
| `share` | クリア画面の「Xでシェア」を押したとき | `method`（`x`） |

取り扱いの案内は `privacy/index.html` の「4. アクセス解析について」。
